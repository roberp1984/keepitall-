# CLAUDE.md — KeepItAll (working name)

## What we are building
A self-serve web app that lets air passengers claim their flight delay/cancellation
compensation **themselves** under EU261 and UK261, instead of paying claim companies
25–35% of their payout.

- Free: eligibility check + how much they are owed.
- Paid (one-time, ~€19 / £17 per claim): a ready-to-send claim pack.
- Positioning: "Your airline owes you up to €600. Claim companies take a third. Keep it all."
- Market: English-speaking travellers flying in/out of the UK and EU.

## Non-negotiable product rules
1. **Eligibility and amounts are decided by deterministic code, never by the LLM.**
   The LLM only writes letter text from structured, already-validated facts.
2. Rules must be **versioned and configurable** (`/lib/rules/`). EU261 is being reformed
   (political agreement June 2026, formal adoption pending). Current rule for any flight
   today: compensation for arrival delay ≥ 3h, cancellation, or denied boarding.
   Keep thresholds, amounts and deadlines in data files, not hard-coded logic.
3. Every output shows: "This is not legal advice. We provide templates and information."
4. Never promise an outcome. Use "you may be entitled to".
5. Mobile-first. Most traffic comes from TikTok/Instagram on phones.
6. Collect the minimum personal data needed. GDPR/UK GDPR compliant. No selling data.

## Stack
- Next.js (App Router) + TypeScript (strict) + Tailwind + shadcn/ui
- Supabase (Postgres) for claims and orders
- Stripe for payments (Stripe Checkout; we are the seller and handle VAT via OSS/UK VAT. Lemon Squeezy and Paddle rejected the business)
- Anthropic API for letter drafting (model: `claude-sonnet-5-5`)
- Resend for transactional email
- `@react-pdf/renderer` for PDF generation
- PostHog for funnel analytics
- Deploy on Vercel

## Core flow (MVP)
1. **Landing** → CTA "Check my flight (free, 60 seconds)".
2. **Checker wizard** (one question per screen, progress bar):
   - Departure airport, arrival airport (autocomplete by IATA/city)
   - Airline (autocomplete), flight number, date
   - What happened: delayed / cancelled / denied boarding
   - Arrival delay in hours (or for cancellations: notice given + rerouting arrival time)
   - Reason the airline gave (technical, crew, weather, strike, ATC, none, other)
3. **Result screen**: regime (EU261 / UK261 / not covered), amount per passenger,
   number of passengers → total, strength of case (strong / possible / unlikely + why),
   and deadline warning if relevant.
4. **Paywall**: "Get your claim pack — €19". Stripe Checkout, guest checkout allowed.
5. **After payment**: collect names of passengers, booking reference, email, postal address.
6. **Claim pack** (shown on page + emailed + PDF):
   - Claim letter to the airline (citing the regulation and articles)
   - Step-by-step "how to send it" for that airline (claim form URL or email from `/data/airlines.json`)
   - Escalation letter (after 30 days / 8 weeks without answer) to the relevant
     national enforcement body or ADR scheme
   - Reply templates for the most common airline refusals ("extraordinary circumstances", vouchers)
7. Order and claim saved in Supabase with status for future follow-up emails.

## Rules engine (`/lib/rules/`)
- `scope.ts`:
  - EU261: departing from an EU/EEA/CH airport (any airline), or arriving in EU/EEA/CH on an EU/EEA/CH carrier.
  - UK261: departing from a UK airport (any airline), or arriving in the UK on a UK or EU carrier.
  - Otherwise: not covered → show honest message and suggest Montreal Convention / refund rights info.
- `distance.ts`: great-circle distance (haversine) between airports using the OurAirports
  open dataset (`/data/airports.json`, generated by a script from the public CSV).
- `amounts.ts` (data-driven):
  - EU261: €250 (≤1,500 km), €400 (intra-EU >1,500 km or 1,500–3,500 km), €600 (>3,500 km)
  - UK261: £220, £350, £520 equivalents of the same bands
  - 50% reduction when rerouted and arrival delay is within the Art. 7(2) limits (2h/3h/4h by band)
- `extraordinary.ts`: classify the airline's stated reason → strong / disputed / weak case.
  Technical faults and crew issues are generally NOT extraordinary; weather, ATC, security
  and third-party strikes usually are. Airline staff strikes generally are not.
- `deadlines.ts`: limitation periods per jurisdiction as a data table. **Each value must be
  verified by a human before launch** — mark unverified entries with `verified: false`
  and do not display them until verified.
- Full unit test coverage for the rules engine (Vitest). Add test cases for every band and edge case.

## Data files (`/data/`)
- `airports.json` — IATA, name, city, country, lat, lon, isEU/EEA/CH, isUK
- `airlines.json` — IATA code, name, country, isEU, isUK, claim form URL, claims email, notes
- `enforcement-bodies.json` — country → body name, URL, ADR scheme if any
Start with the 30 airlines with the most delays in Europe; human verifies URLs.

## LLM usage (`/lib/letters/`)
- Input: a typed `ClaimFacts` object (already validated). Output: letter text only.
- System prompt: firm, polite, concise, cites Regulation (EC) 261/2004 or UK261 articles,
  states the amount, gives a 14-day deadline to respond, requests bank transfer (not vouchers).
- Never let the model change amounts, dates or eligibility. Template the numbers in after generation
  or validate that the output contains the exact amount.
- Fallback: a static template if the API fails.

`check_started`, `check_completed`, `result_eligible`, `result_not_eligible`,

## Code conventions
- Small, pure functions in `/lib`. No business logic inside React components.
- Server actions or route handlers for anything touching payments, DB or the LLM.
- Secrets only in env vars. Provide `.env.example`.
- Webhook from Stripe is the single source of truth for "paid".
- Run `npm run lint`, `npm run typecheck` and `npm test` before saying a task is done.

## Out of scope for MVP
User accounts, automatic flight status lookup via API, submitting claims on the user's
behalf, non-flight claims (parking, deposits, baggage). Add later, one at a time.
